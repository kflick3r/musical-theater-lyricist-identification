# Identifying Musical Theater Lyricists Using NLP and Stylometry

NLP Final Project investigating whether text classifiers can identify musical theater lyricists from song lyrics and generalize to songs from unseen musicals.

## Research Questions

1. How does TF-IDF with Logistic Regression compare with pretrained text embeddings and a classifier?
2. Do models generalize to songs from musicals not included in training?

## Lyricists

- Oscar Hammerstein II
- Stephen Sondheim
- Stephen Schwartz
- Jason Robert Brown

## Planned Evaluation

Accuracy, precision, recall, F1, and confusion matrices.
